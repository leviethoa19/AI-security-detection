# Project plan

The approved detailed plan is maintained as the user-facing deliverable in [`outputs/PROJECT_PLAN.md`](../outputs/PROJECT_PLAN.md).

Implementation follows these fixed priorities:

1. Product semantics before model selection
2. One-camera prerecorded replay before live input
3. Event-level evaluation before UI polish
4. Explainable temporal risk before a learned risk model
5. Secure incident metadata and short evidence clips instead of continuous cloud video
6. Firearm-like visual evidence as the first narrow high-risk class
